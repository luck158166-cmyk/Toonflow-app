- 投产预检与实际付费 POST 分别检查。授权保存片段项目、剧集、序号与输入哈希；首次执行的供应商请求复用宿主 fetch 注入，在媒体准备后、实际 POST 前重新编译当前方案、核对价格/复核/凭据及有效期，并限制一次提交。原生恢复不使用首发包装，不因参考图后来过期、更换凭据或用户再次点击而重新生成已成功视频。保存方案不冻结时间，临近到期提醒也不改变方案版本。

- 补充图片专用独立进程验证：下载前直接退出后恢复同一原图并采用；再次启动复用参考版本且零网络；提交后无回执及原链接 403 失效均不重发图片 POST，预留费用保持待核对。原视频冷启动/幂等、旧手动原图与备份、生产预算绑定回归通过。浏览器实测四张人物图的 7 天内提醒及未授权生成按钮禁用；使用 QA 时钟推进 24 天，无真实费用。
- 生产包、服务端、Web 类型检查及服务端/Web 构建通过（Web 保留既有大包提醒）。下一步继续视频候选采用、片段/镜头时间线与本地合成闭环，并完善历史资产任务入口和自动质检；现有 2 人物协议演练不等于生产级或无人值守验收。真实 API 0 次、费用 0 元；安装包未更新，长期目标保持未完成。

## 片段投产预检、授权与首次生成（2026-11-07）
